# Technical SEO and 404 Diagnostics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement technical SEO essentials (`sitemap.ts`, `robots.ts`, canonical URLs) and diagnose 404 issues without breaking site functionality.

**Architecture:** Utilize Next.js 16 App Router metadata routes (`sitemap.ts`, `robots.ts`) and hierarchical metadata in server layouts (`src/app/layout.tsx`, `src/app/work/layout.tsx`, `src/app/tools/layout.tsx`, `src/app/about/layout.tsx`).

**Tech Stack:** Next.js 16.2.3 (App Router), React 19.2.4, TypeScript 5.

## Global Constraints
- Target domain: `https://losereasp.com`
- Canonical routes: `/`, `/work`, `/tools`, `/about`
- No catch-all redirects (do not redirect 404 to `/`)
- Do not create unconfirmed project routes (e.g. `/work/[slug]`)
- Do not modify design, portfolio data, or media
- Clearly distinguish confirmed fixes from unconfirmed GSC 404 notifications in the final report
